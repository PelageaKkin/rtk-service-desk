# Реестр User Stories

## Must have (Обязательно для MVP)

**SD-01. Вход в систему**
*Как сотрудник техподдержки, я хочу заходить на сайт по логину и паролю, чтобы другие люди не видели заявки клиентов.*
- **Критерии приемки:** Если ввести правильные данные - открывается главная страница. Если неправильные - появляется красная надпись "Ошибка входа".

**SD-02. Создание заявки**
*Как клиент, я хочу заполнить форму с проблемой на сайте, чтобы инженеры увидели её и начали решать.*
- **Критерии приемки:** В форме есть поля "Тема", "Описание" и "Приоритет". Если не заполнить тему, форма не отправится. После отправки заявка появляется в общем списке.

**SD-03. Список всех заявок**
*Как инженер, я хочу видеть таблицу со всеми заявками, чтобы понимать, сколько у меня работы.*
- **Критерии приемки:** В таблице есть номер заявки, тема, статус и дата. Новые заявки находятся вверху списка.

**SD-04. Назначение ответственного**
*Как руководитель, я хочу выбирать инженера из списка в карточке заявки, чтобы никто не забыл про клиента.*
- **Критерии приемки:** В заявке можно выбрать сотрудника. После этого статус заявки меняется на "В работе".

**SD-05. Изменение статуса**
*Как инженер, я хочу нажимать кнопку "Решено", когда починил проблему, чтобы руководитель видел результат.*
- **Критерии приемки:** Можно выбрать статус: "Новая", "В работе" или "Закрыта". Изменения сразу сохраняются.

## Should have (Желательно, но можно позже)

**SD-06. Комментарии к заявке**
*Как инженер, я хочу писать комментарии под заявкой, чтобы уточнить у клиента детали.*
- **Критерии приемки:** Под заявкой есть поле для ввода текста. Все комментарии видны в виде ленты.

**SD-07. Поиск по заявкам**
*Как инженер, я хочу ввести номер заявки в строку поиска, чтобы быстро её найти.*
- **Критерии приемки:** Строка поиска находится над таблицей. Поиск работает по теме и номеру заявки.

**SD-08. Уведомление о новой заявке**
*Как инженер, я хочу видеть цифру новых заявок в углу экрана, чтобы не пропустить срочное обращение.*
- **Критерии приемки:** Рядом с иконкой профиля появляется красный кружок с числом новых заявок.

## Could have (Было бы круто добавить)

**SD-09. Простой отчет**
*Как руководитель, я хочу видеть простую статистику (сколько заявок закрыто, а сколько в работе), чтобы оценивать работу команды.*
- **Критерии приемки:** На отдельной странице выводится текст и цифры: "Всего заявок: 10. Решено: 5. В работе: 5".

**SD-10. Выгрузка в Excel**
*Как аналитик, я хочу нажать кнопку "Скачать", чтобы сохранить заявки в таблицу Excel.*
- **Критерии приемки:** На странице со списком есть кнопка "Скачать в CSV". Файл скачивается на компьютер.

## Won't have (В этой версии делать не будем)

**SD-11. Бот в Telegram**
*Как клиент, я хочу писать в Telegram-бота, чтобы не заходить на сайт.*
- **Причина отказа:** Нам не хватит времени. Отложим на будущее.
