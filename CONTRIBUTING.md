#Правила работы с репозиторием
-"main" - релизный код.
-"develop" - ветка интеграции.
-"feature/<номер_задачи>_<краткое_описание>" - разработка новых функций.

##Commits
Формат: "<тип>(<область>): <краткое описание>"

## Merge Request
1. Создать feature-ветку от "develop"/
2. Сделать коммиты по стандарту.
3. Отправить ветку в удаленный репозиторий.
4. Пройти Code Review у Team Lead.
5. После одобрения - слияние.
